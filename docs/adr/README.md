# Architecture Decision Records

One file per decision, numbered, never rewritten once accepted — superseded instead.

Use an ADR when a decision would otherwise have to be re-derived from scratch by whoever
touches the area next, or when someone might reasonably undo it without realising what it
was protecting.

Decisions that constrain safety or security also get a line in `CLAUDE.md`, because that is
the file an agent session reads first.

```
0001-short-title.md   Status · Context · Decision · Consequences · Standard sections engaged
```
